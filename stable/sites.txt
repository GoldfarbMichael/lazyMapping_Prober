# sites.txt -- Stage 4 website-fingerprinting class list.
#
# Format:  <slug><TAB><url>       ('#' comments and blank lines are skipped)
#
# The SLUG is the class label. It becomes the directory name at server.py's /collect
# (data/{config}/{slug}/{n}.csv) and therefore the key in the .h5 "label_map" that the
# off-machine classifier reads -- so it must match ^[A-Za-z0-9._-]+$ and be unique.
# NEVER put a URL in the slug field: os.path.join() would turn "https://x.com" into a
# nested "https:/x.com/" directory, and csv_to_h5.py's one-level class scan would then
# find zero CSVs and abort the finalize.
#
# Comment out a site with '#' to drop it from the run -- website_orchestrator.c reads this
# file at startup, so no rebuild is needed. The run cost is
# (#uncommented sites) x SAMPLES_PER_CLASS x #NoC x ~8 s, so trimming this list is the
# main lever on wall time. See run_website_sweep.sh for the budget table.
#
# Ordering here does not matter: the orchestrator sweeps round-robin (outer loop =
# iteration, inner = site), so every site's samples are spread across the whole run and
# the classifier cannot learn time-of-day / network drift instead of the site.
